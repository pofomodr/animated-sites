# animated-sites

Repository dedicated to animated sites by **pofomodr**

## 🎨 High-Quality Animated Website

This repository contains a sophisticated, production-ready animated website with:

- ✨ Interactive particle background animations
- 🎭 Smooth scroll-triggered animations
- 🖱️ Custom cursor with trail effects
- 📱 Fully responsive design
- 🎯 Modern, immersive user experience
- ⚡ Performance-optimized animations
- ♿ Accessibility-first approach

## 🚀 Features

### Visual Effects
- **Particle System**: Dynamic particles that respond to mouse movement
- **Floating Elements**: Subtle background bubbles with smooth animations
- **Geometric Shapes**: Animated shapes in the hero section
- **Gradient Effects**: Beautiful color transitions throughout
- **Glow Effects**: Soft glows on interactive elements

### Interactive Elements
- **Custom Cursor**: Magnetic cursor with trail
- **Hover Effects**: Smooth animations on hover
- **Tilt Effects**: 3D perspective on cards
- **Magnetic Buttons**: Buttons that follow cursor
- **Scroll Animations**: Elements reveal on scroll

### Structure
- **Hero Section**: Immersive landing with animated visuals
- **Showcase**: Portfolio of animated projects
- **Features**: Highlighting animation capabilities
- **About**: Team and statistics
- **Contact**: Form with animations
- **Footer**: Complete site navigation

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with animations
- **Vanilla JavaScript**: No dependencies
- **CSS Variables**: Easy theming
- **Canvas API**: Particle animations
- **Intersection Observer**: Scroll animations
- **Request Animation Frame**: Smooth animations

## 🎭 Animation Techniques

1. **Canvas Particle System**: Custom particle animations with physics
2. **CSS Animations**: Keyframe animations for various effects
3. **Scroll-Triggered Animations**: Elements animate as they come into view
4. **Mouse-Following Elements**: Particles and cursor respond to mouse
5. **Counter Animation**: Smooth number counting
6. **Parallax Effects**: Depth perception on scroll
7. **Tilt Effects**: 3D perspective on cards

## 🚀 How to Use

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/pofomodr/animated-sites.git
   cd animated-sites
   ```

2. Open `index.html` in your browser:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   
   # Or simply open index.html directly
   ```

3. View in browser at `http://localhost:8000`

### Customization

- **Colors**: Update CSS variables in `styles.css`
- **Content**: Edit `index.html`
- **Animations**: Modify `main.js`
- **Add Pages**: Create new HTML files and link them

## 🎨 Customization Guide

### Change Color Scheme

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary: #6366f1;
    --secondary: #ec4899;
    --accent: #06b6d4;
    /* ... */
}
```

### Add New Section

1. Add HTML in `index.html`
2. Add styles in `styles.css`
3. Add scroll animation in `main.js`

### Modify Particles

Edit the particle system in `main.js`:
- Change particle count
- Adjust colors
- Modify behavior
- Change connection logic

## ⚡ Performance Tips

- **Particle Count**: Reduce for better performance on mobile
- **Animation Complexity**: Simplify for older devices
- **Reduced Motion**: Respect user preferences
- **Throttling**: Use for scroll/mouse events
